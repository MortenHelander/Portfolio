## Thinking, thinking and thinking

This week we were given the task of starting our semester project, we have to build our first API and doing it solo!
Over the summer I built a small chess API for classic chess using SVG and pure java logic, my idea for the semester project is to rebuild and extend chess API into a fully fletched game. Currently my idea is to use a Stockfish which is an open source chess engine and have different game modes. At least for now the idea is to make a training mode and a completely ridicoulus "gameified" version where you can draw powerups and the AI can move for the player either helping or sabotaging.
In this project I've setup Claude (the AI) to work as a teacher, that provides questions and reflections and sometimes pseudo-code when I ask for help instead of just handing me finished code, it's also what I did for when I started this project because I quickly learned the satisfaction of actually solving a problem instantly vanishes as soon as you get the answer handed to you.
